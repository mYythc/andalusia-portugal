# 安达卢西亚 × 葡萄牙｜公开行程

手机适配的独立静态网页。无依赖、无个人电子车票或订单号。

## 发布到 GitHub Pages
1. 登录 GitHub 用户名 `myythc`，新建 **Public** 仓库 `andalusia-portugal`。
2. 在仓库根目录上传 `index.html`，提交至 `main`。
3. 打开 **Settings → Pages → Build and deployment**，选择 **Deploy from a branch**，分支 `main`，目录 `/(root)`，保存。
4. 发布成功后链接为 `https://myythc.github.io/andalusia-portugal/`。

注意：仓库公开，勿上传原始票据、二维码、身份证件和包含订单号的文件。
